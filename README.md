# 🚑 Quick Aid

A web-based helpline and emergency assistance information project designed to make useful support information easier to find.

## Overview

Quick Aid provides a simple website interface for accessing helpline-related information. The project focuses on presenting important assistance details in an accessible format.

## Features

- Helpline information
- Simple, accessible website layout
- Informational pages
- Responsive front-end experience

## Tech Stack

- HTML
- CSS
- JavaScript

## Run Locally

```bash
git clone https://github.com/Lakshayy2406/Quick-Aid.git
cd Quick-Aid
```

Open `index.html` in your browser, or run it with VS Code Live Server.
